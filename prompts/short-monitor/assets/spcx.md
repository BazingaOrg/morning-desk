# SPCX / SpaceX

## Thesis

空头监控跟踪 SpaceX 普通股正式上市后的供给、融资、发射与商业化节奏相对市场嵌入预期的偏离。仅在本质经营/资本结构变量恶化、预期差扩大、价格确认与明确催化剂同时成立时，才允许将 SSPC 列为下一常规时段条件候选。

## 本质变量变化（计入 Fundamental Shift）

- 发射节奏、可用性或关键任务失败相对指引显著恶化
- 融资条件、稀释、资本开支或流动性约束实质变差
- 星链/商业航天收入、利润率或订单可见度相对官方披露走弱
- 监管、牌照、频谱或出口限制构成可核验的经营约束
- 供给冲击：锁定期后可验证的大规模解禁须配合价格确认，解禁本身不加分

不算本质变化：估值高、涨幅大、单条媒体利空、战争标题、单一研报、单一技术破位。

## 结构性无效（Stop / Invalidation）

- 底层 SPCX 收复并站稳关键 swing high / 结构阻力（以底层为准，不用 SSPC 走势替代）
- 官方披露证明先前「恶化」叙事被证伪（发射/融资/收入恢复超预期）
- Thesis 所依证据被撤回、更正或与第二来源冲突且无法裁定

## 催化剂类型

- SEC / 公司 IR：财报、融资、重大合同、Capex、供给与锁定期披露
- 可核验的产业/监管节点（牌照、频谱、出口）
- 宏观流动性与风险偏好仅作背景，不得单独抬分

## 资产专属规则

- historyStartDate / officialFirstSession：`2026-06-12`；更早 bars 一律丢弃
- 样本不足 → 长周期指标 `N/A`，不得拼接旧实体历史
- 估值-only 路径 Score 封顶 40（全局规则）
- 执行工具：`SSPC`（静态；不接长桥；缺报价 → None）
- 价格确认仅用底层 SPCX
